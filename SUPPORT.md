Support

Squared is currently under active development and is undergoing a ground-up rewrite.

Getting Help

For questions, problems, or suspected bugs, please open a GitHub issue with:

- A clear description of the problem.
- Steps to reproduce it.
- Relevant compiler, operating system, and build information.
- Error messages or logs when applicable.
- A minimal example when possible.

Before Opening an Issue

Please check the existing issues and documentation first.

Expectations

Squared is a rapidly evolving project. APIs and behavior may change without notice while the rewrite is in progress.

Support is provided on a best-effort basis. There are no guarantees of backward compatibility during the rewrite.

The "legacy-toy" branch is historical and is not supported.
