# 1. Output

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, world!\n";
    return 0;
}
```

- `#include <iostream>` borrows the code that prints and reads text.
- `main` is where every program starts.
- `std::cout << ...` sends text to the screen. `\n` ends the line.
- `return 0;` tells the system the program finished without trouble.
