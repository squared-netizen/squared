Contributing to Squared

Squared is currently undergoing a ground-up rewrite and is changing rapidly.

Current Status

The "main" branch contains the current rewrite and should be considered active development.

The "legacy-toy" branch contains the previous implementation. It is preserved for historical reference and is not maintained.

Contributions

Contributions are welcome, but please understand that APIs, 
architecture, and project structure may change significantly while the rewrite is underway.

Anyone wishing to contribute muat DM the developer me at
: S.O.Teric1@proton.me


Before making substantial changes:

1. Check the current documentation and issues.
2. Open an issue to discuss large changes or new features.
3. Keep changes focused and avoid unrelated refactoring.
4. Make sure existing tests continue to pass.
5. Update documentation when changing public APIs or behavior.

Pull Requests

Pull requests should:

- Clearly describe what was changed and why.
- Include tests for new or changed behavior where practical.
- Avoid introducing unnecessary dependencies.
- Follow the existing project style.

The project owner has final authority over architectural and design decisions.

Development Branch

"main" is the primary development branch.

The old implementation is preserved separately in "legacy-toy" and should not be used as the basis for new development.
