# struct CellAttributes

*Defined at [term/cell_attributes.cppm:15](../../../../term/cell_attributes.cppm#L15)*



**brief** How a cell's character is drawn (ECMA-48's SGR), one bit each.

 `bold` and `faint` are the two intensities; a terminal that shows bold as a brighter colour does so when it draws, the cell keeps the colour it was given.
