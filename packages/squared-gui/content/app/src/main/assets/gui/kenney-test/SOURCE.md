# Kenney UI Pack test skin

These images are selected, unmodified files from Kenney's **UI Pack 2.0**:

- source page: <https://kenney.nl/assets/ui-pack>
- original archive: `kenney_ui-pack.zip`
- license: Creative Commons Zero (CC0 1.0)

The files were renamed locally to describe their role in the Squared GUI skin
test. `skin.atlas` is Squared project metadata and is not part of the original
Kenney archive.
