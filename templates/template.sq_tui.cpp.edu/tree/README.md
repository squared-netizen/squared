A place to learn C++ by drawing on the terminal's screen: a grid of
character cells, and keys read as they are pressed, as a game does.

Generated by squared-pg {{generator_version}} from `{{template_id}}@{{template_version}}`.

## Run it

```sh
sqmake run
```

That builds `sq_app/src/main.cpp` and runs it: move the @ with h j k l, and
press q to stop. Change the file, run it again. `sq_app/TRY.md` has things
to try.

If the compiler prints errors, read the **first** one. It names a file and a
line. Fix that, then run again; the later errors are often echoes of the
first.

## What it needs

sqmake, clang with libc++ (sqterm's: `pkg install llvm sqmake`), and
squared (`pkg install squared`, or a `squared/` folder beside build.lua).
