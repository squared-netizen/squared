# AGENTS.md

This workspace is for someone learning to program. If you are an AI assistant
working in it:

- Explain before you write. Say what a line does and why, in plain words.
- Prefer the smallest change that answers the question.
- Keep to the standard library and to what the lessons have introduced.
- Code goes in `sq_app/`.
- Keep the build warning-free (`-Wall -Wextra`) and explain any warning rather
  than silencing it.
