## Run it

```sh
make run
```

That builds `sq_app/src/main.cpp` and runs it. Change the file, run it again.

If the compiler prints errors, read the **first** one. It names a file and a
line. Fix that, then run again; the later errors are often echoes of the first.

## Adding files

Every `.cpp` file directly inside `sq_app/src/` is compiled together into one
program, and exactly one of them may contain `main`. Headers go in
`sq_app/include/`.
