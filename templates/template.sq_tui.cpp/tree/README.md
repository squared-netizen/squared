A character-cell program: it takes the terminal's whole screen, draws in its
grid of cells and reads keys as they are pressed, as an editor or a game

sqmake, and squared (`pkg install squared`, or a `squared/` folder beside

## How it draws

`board::draw` draws the whole screen again from the state every time; the
terminal is sent only the cells that changed, so drawing everything is
cheap and nothing is left over from the last frame. `sq::tui::Terminal`
puts the terminal back as it found it however the program ends, a crash
included.

`sq::tui::Test` is a screen with no terminal behind it: it renders into
squared's own terminal emulator, the one sqterm draws, so a test asserts on
what a person would see (`sq_app/test/board_test.cpp`).
